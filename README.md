This project was developed for the **Object-Oriented Programming in Java** course at the **Polytechnic Institute of Portalegre**, Portugal.

## 📚 Description

This project consists of creating a **military strategy game**, where the player can create different combat units, group them into armies, and simulate battles between them using **Object-Oriented Programming (OOP)** principles.

The simulation takes place on a user-defined board and allows multiple strategic interactions and decisions, such as movement, range, and combat between units.

## ⚙️ Features

* **Unit Creation**

  * Warriors with armor
  * Archers with weapon choice (bow or crossbow)
  * Wizards with a limited number of spells per simulation

* **Army Management**

  * Create, list, and organize units

* **Board Configuration**

  * Define board size (rows and columns)
  * Manual or random positioning of armies

* **Combat Simulation**

  * Automatic unit movement
  * Combat based on range, strength, and unit type
  * Display the status after each simulation step

* **Data Validation**

  * Robust input handling with exception management
  * Validation of positions and collisions

* **Safe Termination**

  * Option to safely end the game by the user

## 🛠️ Technologies Used

* **Java** (JDK 17 or higher)
* **Object-Oriented Programming**
* **Inheritance, polymorphism, and encapsulation concepts**

## 🏗️ Main Project Structure

* `Unit.java` - Represents a game unit.
* `Army.java` - Represents a collection of units.
* `Board.java` - Represents the game board.
* `Game.java` - Main class to run the simulation.

## 📚 Descrição

Este projeto consiste na criação de um **jogo de estratégia militar**, no qual o jogador pode criar diferentes unidades de combate, agrupá-las em exércitos e simular batalhas entre eles, utilizando os princípios de **Programação Orientada a Objetos (POO)**.

A simulação ocorre num tabuleiro de dimensão definida pelo utilizador e permite diversas interações e decisões estratégicas, como movimentação, alcance e combate entre unidades.

## ⚙️ Funcionalidades

* **Criação de Unidades**

  * Guerreiros com blindagem
  * Arqueiros com escolha de arma (arco ou besta)
  * Feiticeiros com limite de feitiços por simulação

* **Gestão de Exércitos**

  * Criação, listagem e organização de unidades

* **Configuração do Tabuleiro**

  * Definição do tamanho (linhas e colunas)
  * Posicionamento manual ou aleatório dos exércitos

* **Simulação de Combate**

  * Movimentação automática das unidades
  * Combate com base no alcance, força e tipo de unidade
  * Exibição do estado após cada passo da simulação

* **Validação de Dados**

  * Entrada de dados robusta com tratamento de exceções
  * Validação de posições e colisões

* **Finalização Segura**

  * Opção para terminar o jogo de forma segura pelo utilizador

## 🛠️ Tecnologias Utilizadas

* **Java** (JDK 17 ou superior)
* **Programação Orientada a Objetos**
* **Conceitos de herança, polimorfismo e encapsulamento**

## 🏗️ Estrutura Principal do Projeto

* `Unit.java` - Representa uma unidade do jogo.
* `Army.java` - Representa uma coleção de unidades.
* `Board.java` - Representa o tabuleiro do jogo.
* `Game.java` - Classe principal para executar a simulação.
